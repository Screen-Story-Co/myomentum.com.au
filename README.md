# myomentum.com.au

Myotherapy practice site for **Myomentum** (Phil Papadopoulos) — clinical myotherapy in St Kilda.

Migrated from Weebly (myomentum.com.au) to Astro 5 static site on ScreenStory platform.

- **Preview:** https://myomentum.preview.screenstory.co (via ScreenStory Studio)
- **Production:** https://myomentum.com.au (currently Weebly — cutover pending DNS)

## Pages

Home, About, Bookings (Cliniko embed), Blog (2 posts), Contact (map + form + hours). Legacy /blog.html and .html paths handled via redirects.
